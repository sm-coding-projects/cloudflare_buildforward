# Build Forward Homes

This is the official website for Build Forward Homes, a luxury custom home builder in New South Wales, Australia.

## About

Build Forward Homes specializes in crafting modern, functional homes with a focus on luxury detail and a collaborative client process. They serve the Greater Sydney, Blue Mountains, Illawarra, and Central Coast regions.

## Website Features

*   **Single-Page Application (SPA):** The website is a fast, modern single-page application for a seamless user experience.
*   **Portfolio:** Features a gallery of their signature projects with high-quality images.
*   **Contact Form:** Includes a functional contact form with email validation.
*   **Responsive Design:** The website is fully responsive and works on all devices.

## Tech Stack

*   HTML5
*   CSS3 (with custom properties and a mobile-first approach)
*   JavaScript (vanilla JS for routing, DOM manipulation, and interactions)

## How to Run Locally

1.  Clone this repository.
2.  Open the `index.html` file in your web browser.
